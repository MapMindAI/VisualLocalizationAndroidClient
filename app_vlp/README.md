# app_vlp

Android AR app module with optional `mobili::vlp` integration and a built-in gRPC stream server.

## gRPC stream

- Server endpoint: `<phone-ip>:50051` (plaintext gRPC)
- RPC: `vlp.FrameStreamService/StreamFrames` (server streaming)
- Payload format: binary frame
  - Header (little-endian, 64 bytes): magic, timestamp, width, height, intrinsics, pose
  - Body: JPEG bytes for full RGB image
- JPEG conversion is done only in the gRPC send path (when a subscriber is ready), not in every camera-frame update.

## Python test client

Script:

- `python/ws_stream_client.py`

Install dependency:

```bash
pip install grpcio opencv-python numpy
```

Run via ADB port forward:

```bash
adb forward tcp:50051 tcp:50051
python3 python/ws_stream_client.py --host 127.0.0.1 --port 50051
```

The client displays the stream live in OpenCV with overlaid intrinsics and pose.

## Optional mobili::vlp library

`mobili::vlp` is disabled by default.

- Enable it with Gradle property:

```bash
./gradlew :app:assembleDebug -PenableMobiliVlp=true
```

- Default (disabled):

```bash
./gradlew :app:assembleDebug
```

When disabled, the app runs without linking `libmobili_vlp_api.so`.

## Run DA3 ONNX on Android with MNN

This app now supports optional DA3 inference through MNN.

### 1) Prepare MNN runtime files

Expected layout:

- `libs/mnn/include/MNN/...`
- `libs/mnn/lib/arm64-v8a/libMNN.so`

### 2) Convert ONNX to MNN

Input model:

- `python/models/da3_small_2_392x224_sim.onnx`

Run converter:

```bash
app_vlp/scripts/convert_da3_to_mnn.sh
```

Output model (Android asset):

- `app_vlp/app/src/main/assets/models/da3_small_2_392x224_sim.mnn`
- `app_vlp/app/src/main/assets/models/da3_small_2_392x224_sim.mnn.weight` (if generated by converter)

### 3) Build app with MNN enabled

```bash
cd app_vlp
./gradlew :app:assembleDebug -PenableMnnDa3=true
```

### 4) Run in app

- Open app and wait for camera stream to start.
- Tap `Run DA3 MNN`.
- First tap caches frame-1.
- Second tap runs pair inference on `(frame-1, frame-2)` and shows timing/output info in UI.

Notes:

- DA3 input is pair tensor `[1,2,3,224,392]`.
- Current integration uses two sequential gray frames and replicates gray to RGB channels.
- Native loader copies `.mnn` and optional `.mnn.weight` from assets into app cache and loads with `MNN::Interpreter::createFromFile`.
